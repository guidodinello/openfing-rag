# ROUTES STRUCTURE

This the URL structure for the routes of this project:

`/` - initial menu page  
`/sign-in` - login page  
`/players` - player list page  
`/statistics` - statistics page (filter go on the query param, this is usefull to share)

<b>GAME STRUCTURE</b>

here `game-name` should indicate the name of the current selected game.

`/game-name/` - game tutorial page  
`/game-name/level` - game level page  
`/game-name/preview` - game preview page
`/game-name/play` - game page  
`/game-name/review` - game review page  
`/game-name/error` - error page  
`/game-name/success` - success page

each game name is:

-   `rain`
-   `sequence`
-   `chess`
